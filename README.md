# Escola Castelinho da Criança

Site institucional da Escola Castelinho da Criança, no Paranoá (Brasília-DF): https://escolacastelinhodacrianca.com.br/

Site estático (HTML, CSS e JS), sem build. Para ver localmente, abra o `index.html` no navegador ou rode:

```sh
python3 -m http.server
```

- `CLAUDE.md`: dados oficiais da escola e regras do projeto.
- `REVISAO.md`: o que foi corrigido e melhorado na revisão, e o que falta confirmar com a escola.
- `imagens/CATALOGO.md`: o que aparece em cada foto e onde ela é usada.
- `referencia/`: protótipo antigo e especificação da revisão (só referência, com dados desatualizados).
